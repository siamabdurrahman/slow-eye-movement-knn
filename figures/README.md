# Figure index

This directory contains a curated set of figures from the original slow-eye-movement KNN study. Individual accuracy, precision, recall and F1 plots that duplicate the combined metric figure are intentionally omitted.

| File | Description |
| --- | --- |
| [`research-workflow.png`](research-workflow.png) | Original signal-processing and KNN classification workflow |
| [`sample-signal-series.png`](sample-signal-series.png) | Six representative signal series from the training data |
| [`slow-eye-movement-example.jpg`](slow-eye-movement-example.jpg) | Representative slow-eye-movement signal |
| [`non-slow-eye-movement-example.jpg`](non-slow-eye-movement-example.jpg) | Representative non-slow-eye-movement signal |
| [`knn-metrics-by-neighbours.png`](knn-metrics-by-neighbours.png) | Accuracy, macro precision, macro recall and macro F1 across evaluated neighbourhood sizes |

The plots document the archived fixed training/evaluation split and should not be interpreted as subject-wise cross-validation or external-validation results.
